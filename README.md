# 空間モニター（kukan-monitor）

iPadを動かして周囲を見回し、空間に浮かぶ複数のブラウザ画面を操作するアプリです。
Swift Playgrounds（Apple純正・無料）だけで動かせます。Macは不要です。

## iPadで動かす手順

1. App Storeから「Swift Playgrounds」を入れる
2. Safariでこのリポジトリを開き、「Code」→「Download ZIP」
3. 「ファイル」アプリでZIPをタップして展開する
4. 展開したフォルダ内の `KukanMonitor.swiftpm` をタップ（Swift Playgroundsで開く）
5. 再生ボタン（▶）で実行

### うまく開けない場合（貼り付け方式）

1. Swift Playgroundsで「App」を新規作成する
2. `ContentView.swift` の中身を全部消し、このリポジトリの
   `KukanMonitor.swiftpm/ContentView.swift` の内容を丸ごと貼り付ける
3. ARを使う場合は、アプリ設定の「機能」で「カメラ」を追加する（VR表示だけなら不要）

## 使い方

- iPadを動かす：周囲を見回す
- モニターをタップ：手元に大きく開く（普通のブラウザとして操作できる）
- 「空間に戻す」または周囲の暗い部分をタップ：モニターを空間に戻す（動画は再生されたまま）
- 長押ししたままiPadを動かす：モニターを移動
- 「画面操作：○○」：モニターの操作方法を切り替える（次回起動時も保持）
  - 「最大化」：モニターをタップすると手元に大きく開く
  - 「空間で直接」：空間に浮かんだままのモニターに直接タッチして操作する。
    この設定では、移動は「何もない所を長押し」で照準を合わせているモニターが対象になる。
    モニター上部の矢印ボタンで、そのモニターだけ最大化もできる
- ピンチ、または照準を合わせて「拡大」「縮小」：モニターの大きさを変更
- 照準を合わせて「形を変える」：モニターの形を 標準 → 横長 → 縦長 → 正方形 の順に変更
  （「空間で直接」の設定では、モニター上部の四角いボタンでも変更できる）
- 虫めがねボタン（手元に開いているとき）：ページの表示倍率を変更
- 移動スティック（左下の丸いパッド）：見ている向きを基準に、自分が前後左右へ動く。近づくとモニターが大きく見える
- 視点スティック（右下の丸いパッド）：倒した方向に視点が回る
- スティックは長押しすると置き場所を動かせる。メニューから個別に表示/非表示を切り替えられる
- 丸いメニューボタン（左上）：タップでメニューの表示/非表示、ドラッグで移動
- 「視点リセット」：自分の位置を中心に戻し、いま向いている方向を正面にする
- 「空間：○○」：夜空 → クール（水色）→ キュート（ピンク）の順に切り替え
- 「モニターを追加」：見ている方向に新しいブラウザを追加（最大8枚）
- 「ARに切り替え」：背景をカメラ映像にする

## 既知の制限

- Googleアカウントへのログインは、Google側の方針でアプリ内ブラウザから拒否されることがあります
- カメラ映像は画面に表示するだけで、保存も送信もしません
- 閲覧データ（ログイン状態など）はこのアプリの中に保存されます
