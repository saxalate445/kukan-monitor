# 空間モニター（kukan-monitor）

iPadを動かして周囲を見回し、空間に浮かぶ複数のブラウザ画面を操作するアプリです。
Swift Playground（Apple純正・無料）だけで動かせます。Macは不要です。

## iPadで動かす手順

1. App Storeから「Swift Playground」を入れる
2. Safariでこのリポジトリを開き、「Code」→「Download ZIP」
3. 「ファイル」アプリでZIPをタップして展開する
4. 展開したフォルダ内の `KukanMonitor.swiftpm` をタップ（Swift Playgroundで開く）
5. 再生ボタン（▶）で実行

更新するときは、古いフォルダを消してからZIPを落とし直してください。

### うまく開けない場合（貼り付け方式）

1. Swift Playgroundで「App」を新規作成する
2. `KukanMonitor.swiftpm` の中の Swift ファイル5つ（`ContentView` `MonitorView` `SpaceViewController`
   `Controls` `WebAssets`）を、同じ名前のファイルを作って丸ごと貼り付ける
3. ARを使う場合は、アプリ設定の「機能」で「カメラ」を追加する（VR表示だけなら不要）

## 使い方

### 見回す・動く

- iPadを動かす：周囲を見回す
- 視点スティック（右下）：倒した方向に視点が回る
- 移動スティック（左下）：見ている向きを基準に、自分が前後左右へ動く
- スティックは長押しすると置き場所を動かせる
- レーダー（右上）：まわりのモニターを上から見た地図。上が自分の正面。点をタップするとそのモニターの方を向く

### モニターを操作する

- 照準を合わせてタップ：手元に大きく開く（普通のブラウザとして操作できる）
- 「空間に戻す」または周囲の暗い部分をタップ：モニターを空間に戻す（動画は再生されたまま）
- 長押ししたままiPadを動かす：モニターを移動
- ピンチ、または「拡大」「縮小」：モニターの大きさを変更
- 「形を変える」：標準 → 横長 → 縦長 → 正方形
- 「動画を広げる」：ページ内の動画を、モニターの枠いっぱいに広げる（空間に浮かんだまま）。
  広げた動画を見ている間は、映画館のようにまわりが暗くなる
- YouTubeなどの全画面ボタン：動画がiPadの画面いっぱいに表示される（終了すると空間に戻る）

### メニュー（左上の丸いボタンで出し入れ。ドラッグで移動）

- 「モニター」：追加、並べ方、左右のモニターへ向く、拡大縮小、形、動画を広げる
- 「空間」：空間のテーマ（夜空・クール・キュート・シンセウェーブ）、AR、視点リセット、レーダー、音声フォーカス
- 「操作」：画面操作の設定、スティックの表示

#### 並べ方

- アーチ：正面に弧を描いて並べる
- ウォール：上下2段の壁
- シアター：照準を合わせたモニターを正面に大きく、残りを手前下に小さく
- コックピット：正面に3枚、残りを手前の計器盤のように並べる

#### 音声フォーカス

オンにすると、最後に照準を合わせたモニターだけ音が出ます（ほかは消音）。
複数のモニターで動画を流すときに使います。

#### 画面操作

- 「最大化」：照準をモニターに合わせ、画面のどこかをタップすると手元に大きく開く
- 「空間で直接」：照準を合わせたモニター（色付きの枠）だけ、直接タッチして操作できる。
  移動は「枠の外を長押し」、大きさは「枠の外でピンチ」

### ウィジェット（通信なしで動く小さな画面）

「モニターを追加」から選べます：時計、タイマー、メモ、環境音（雨・波・風）。
メモの内容はこのiPadの中だけに保存されます。

## 既知の制限

- 外付けキーボード（Bluetooth含む）が接続されていると、画面のキーボードは表示されません。
  入力欄をタップしてもキーボードが出ないときは、画面上部に原因の手がかりが表示されます
- 「動画を広げる」はページの作りに依存します。動画が見つからないページでは使えません
- 音声フォーカスは、ページ内に埋め込まれた別サイトの動画には効かないことがあります
- Googleアカウントへのログインは、Google側の方針でアプリ内ブラウザから拒否されることがあります
- カメラ映像は画面に表示するだけで、保存も送信もしません
- 閲覧データ（ログイン状態など）はこのアプリの中に保存されます

## 開発用メモ

- `KukanMonitor.swiftpm/WebAssets.swift` は自動生成です。ページ用スクリプトやウィジェットを直すときは
  `dev/bootstrap.js` と `dev/widgets/` を編集し、`python3 dev/build_assets.py` を実行します
