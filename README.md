# 空間モニター（kukan-monitor）

iPadを動かして周囲を見回し、空間に浮かぶ複数のブラウザ画面を操作するアプリです。
Swift Playground（Apple純正・無料）だけで動かせます。Macは不要です。

## iPadで動かす手順

1. App Storeから「Swift Playground」を入れる
2. Safariでこのリポジトリを開き、「Code」→「Download ZIP」
3. 「ファイル」アプリでZIPをタップして展開する
4. 展開したフォルダ内の `KukanMonitor.swiftpm` をタップ（Swift Playgroundで開く）
5. 再生ボタン（▶）で実行

更新するときは、古いフォルダを消してからZIPを落とし直してください。

### うまく開けない場合（貼り付け方式）

1. Swift Playgroundで「App」を新規作成する
2. `KukanMonitor.swiftpm` の中の Swift ファイル5つ（`ContentView` `MonitorView` `SpaceViewController`
   `Controls` `WebAssets`）を、同じ名前のファイルを作って丸ごと貼り付ける
3. ARを使う場合は、アプリ設定の「機能」で「カメラ」を追加する（VR表示だけなら不要）

## 使い方

### 見回す・動く

- iPadを動かす：周囲を見回す
- 視点スティック（右下）：倒した方向に視点が回る
- 移動スティック（左下）：見ている向きを基準に、自分が前後左右へ動く（見えている床の端まで歩ける）
- スティックは長押しすると置き場所を動かせる
- レーダー（右上）：まわりのモニターを上から見た地図。上が自分の正面。点をタップするとそのモニターの方を向く

### モニターを操作する

- 照準を合わせてタップ：手元に大きく開く（普通のブラウザとして操作できる）
- 「空間に戻す」または周囲の暗い部分をタップ：モニターを空間に戻す（動画は再生されたまま）
- 長押ししたままiPadを動かす：モニターを移動
- ピンチ、または「拡大」「縮小」：モニターの大きさを変更
- 「形を変える」：標準 → 横長 → 縦長 → 正方形
- 「近くへ」「遠くへ」：照準のモニターを自分に近づける／遠ざける
- 2本指でひねる：照準のモニターをその場で回す
- モニターの裏に回ると、点線の透明な枠が表示される（そこにモニターがあると分かる）
- モニターは空間のどこにでも置ける。長押しで動かすと、つかんだ距離のまま視線の先へ移動し、自分の方を向く
- 「動画を広げる」：ページ内の動画を、モニターの枠いっぱいに広げる（空間に浮かんだまま）。
  広げた動画を見ている間は、映画館のようにまわりが暗くなる
- YouTubeなどの全画面ボタン：iPadの画面全体ではなく、空間に浮かんだモニターの枠の中で全画面になる
  （モニター上部のバーも隠れる。終了すると元に戻る）

### 見た目

メニュー・お知らせ・スティック・レーダー・キーボード・追加パネルは、iPadOSのコントロールセンターのような
すりガラス調（背景がぼけて透ける）です。モニターの枠は、空間が透ける半透明の板になっています。

### 収納・呼び寄せ

- 「しまう」（「モニター」タブ）：照準のモニター（なければ家具）を空間からしまう
- 「収納・呼び寄せ」（「モニター」「デザイン」タブ）：空間にあるモニターと家具の一覧。
  遠くにあるもの（何m先か表示）も、その場から「しまう／出す」「ここへ（自分の前に呼ぶ）」ができる
- しまったモニターのページは動いたまま（再生中の音楽などは続く）。しまった状態は保存される

### 空間のデザイン（メニューの「デザイン」）

家具を置いて、自分の部屋のように空間を作れます。家具は本物の3D（SceneKit）で描かれ、床に影が落ちます。

- 「家具を置く」：ソファ、1人がけチェア、ローテーブル、ラグ、観葉植物、フロアランプ（明かりつき）、
  本棚、ビーズクッションから選ぶ。見ている床の上に、こちら向きで置かれる
- 家具に照準を合わせると足元に輪が出る（選んだ状態）
  - 長押ししたまま見回す：床の上を移動
  - 2本指でひねる：回転／ピンチ：大きさ
  - 「色を変える」「回す」「大きく」「小さく」「片付ける」：ボタンでも操作できる
- 「大画面を呼ぶ」：前方の遠くに、横長の大きな画面（YouTube）を置く。
  家具の一覧からは、Google や時計の大画面も呼べる
- 「おすすめ配置」：ラグ・ソファ・テーブル・植物・ランプ・本棚・クッションの配置に置き換える（2回押しで確定）
- 家具の配置は自動で保存され、次回も同じ部屋になる

### Apple Pencil で書く（メニューの「ペン」）

指は今までどおり見回しや操作に使い、Apple Pencil で触れたときだけ「書く」になります。
ボタンやメニューの上では書かずに、そのまま押せます。

- ホワイトボード：「ホワイトボードを出す」（または「モニターを追加」→「ホワイトボード」）で、
  空間に白い板を置く。空間に浮かんだままでも、手元に開いても、ペンで直接書ける。
  書いた線はボードごとに保存される。板の上部のボタンで「1つ戻す」「全部消す」（2回押しで確定）
- 空中に描く：何もない所をペンでなぞると、その線が光る3Dの線として空間に残る。
  歩いて回り込むと立体的に見える。描く面までの距離は「空中の距離」（近く／中くらい／遠く）で選ぶ
- 筆圧に合わせて線が太く・細くなる。「色」「太さ」で切り替え
- 消しゴム：「消しゴム」ボタン、または Apple Pencil のダブルタップで切り替え。なぞった線が消える
- 「1つ戻す」：最後に書いた線を取り消す（ボードでも空中でも）
- 「空中の線を消す」：空中の線をすべて消す（2回押しで確定）
- 空中の線は 3D 表示の一部です。「デザイン」→「3D表示」がオフのときは、描きはじめると自動でオンになります

### メニュー（左上の丸いボタンで出し入れ。ドラッグで移動）

- 「モニター」：追加、並べ方、左右のモニターへ向く、拡大縮小、形、動画を広げる、近くへ・遠くへ
- 「デザイン」：家具を置く、大画面を呼ぶ、家具の色・向き・大きさ、片付ける、おすすめ配置、3D表示のオン/オフ
- 「ペン」：ホワイトボード、ペンの色・太さ、空中に描く距離、消しゴム、1つ戻す、空中の線を消す
- 「空間」：空間のテーマ（夜空・クール・キュート・シンセウェーブ）、AR、視点リセット、レーダー、音声フォーカス、
  2階へ上がる／1階へ下りる、照明の色

#### 2階

「2階へ上がる」で、約2.6m上の階へ移動します。2階の床はガラス張りで、1階が透けて見えます。
家具は、いる階の床に置かれます（動かすと、いる階の床へ移ります）。

#### 照明の色

「照明の色」で、家具や空中の線を照らす光の色を R・G・B（0〜255）と明るさのスライダーで変えられます。
色は #RRGGBB でも表示されます。「テーマの色に戻す」で元に戻ります。設定は保存されます。
- 「操作」：画面操作の設定、スティックの表示

#### 並べ方

- アーチ：正面に弧を描いて並べる
- ウォール：上下2段の壁
- シアター：照準を合わせたモニターを正面に大きく、残りを手前下に小さく
- コックピット：正面に3枚、残りを手前の計器盤のように並べる

#### 音声フォーカス

オンにすると、最後に照準を合わせたモニターだけ音が出ます（ほかは消音）。
複数のモニターで動画を流すときに使います。

#### 画面操作

ボタンを押すたびに、次の3つが順に切り替わります。

- 「最大化」：照準をモニターに合わせ、画面のどこかをタップすると手元に大きく開く
- 「直接（照準の1枚）」：照準を合わせたモニター（色付きの枠）だけ、直接タッチして操作できる。
  移動は「枠の外を長押し」、大きさは「枠の外でピンチ」
- 「直接（すべて）」：照準に関係なく、どのモニターも直接タッチして操作できる。
  移動と大きさ変更は、何もない所での長押し・ピンチ（対象は照準のモニター）

### 文字入力（アプリ内キーボード）

入力欄をタップしてもシステムのキーボードが出ない場合、約1秒後にアプリ内キーボードが自動で開きます。
iPadの英語キーボードと同じ比率の QWERTY 配列（⌫ は1.5キー幅、2段目は半キー右へずれ、決定は2キー幅）で、
ローマ字を打つとひらがなに変わります（例：`konnichiha` → こんにちは）。

- 「カタカナ」：カタカナ入力に切り替える。「ABC」で英字、「123」で数字と記号
- 「ー」「。」「、」：長音や句読点。濁点・半濁点・小さい字はローマ字で打てる
  （`ga` → が、`pa` → ぱ、`xtu` または子音を重ねて → っ）
- 「貼り付け」：ほかのアプリでコピーした文字を入れる
- 「決定」：検索や送信を実行する。URL欄の場合はそのページを開く
- 漢字への変換はできません（検索は、ひらがなのままでも多くのサイトで通ります）
- 上の入力欄をタップしてシステムのキーボードが出た場合は、そちらで漢字変換も含めて入力できます
- モニター上部のキーボードのボタンで、いつでも開けます

### ウィジェット（通信なしで動く小さな画面）

「モニターを追加」から選べます：時計、タイマー、メモ、環境音（雨・波・風）。
メモの内容はこのiPadの中だけに保存されます。

## 既知の制限

- 複数のモニターで動画を同時に再生できます。iPad では音の出る動画は同時に1つまでのため、
  2つ目の再生が始まると自動で音声フォーカスに切り替わり、最後に再生した（見ている）画面の音だけを出し、
  ほかの画面は消音のまま再生を続けます。止められた画面は自動で再開します
- モニター（ブラウザ）は常に家具より手前に描かれます（家具の後ろにモニターが隠れることはありません）

- 外付けキーボード（Bluetooth含む）が接続されていると、画面のキーボードは表示されません。
  入力欄をタップしてもキーボードが出ないときは、画面上部に原因の手がかりが表示されます
- 「動画を広げる」はページの作りに依存します。動画が見つからないページでは使えません
- 音声フォーカスは、ページ内に埋め込まれた別サイトの動画には効かないことがあります
- Googleアカウントへのログインは、Google側の方針でアプリ内ブラウザから拒否されることがあります
- カメラ映像は画面に表示するだけで、保存も送信もしません
- 閲覧データ（ログイン状態など）はこのアプリの中に保存されます

## 開発用メモ

- `KukanMonitor.swiftpm/WebAssets.swift` は自動生成です。ページ用スクリプトやウィジェットを直すときは
  `dev/bootstrap.js` と `dev/widgets/` を編集し、`python3 dev/build_assets.py` を実行します
